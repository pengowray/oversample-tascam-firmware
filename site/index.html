Bat detector for the TASCAM Portacapture X8

This page makes a bat detector update file for the X8 from TASCAM's own V2.03 firmware. The firmware never leaves your computer: the page reads it, changes it and saves the result here.

Experimental test build. This is an unofficial patch, not made or supported by TASCAM. It has been tested on one X8 (hardware version 1.00 build 010). Installing the official V2.03 file the same way puts the X8 back to stock. A power cut or a card removed during any update can leave the unit needing repair.

1. Get TASCAM's V2.03 firmware

Download portacapture_x8_fw_v203.zip from TASCAM's Portacapture X8 download page. You can use the zip file as it is, or the #PortaX8_0217.203 file inside it.

2. Choose the file

    Save the update file

    3. Install it on the X8

    1. Power the X8 from USB or the AC adapter, not batteries.
    2. On the X8, turn on SD CARD READER (GENERAL SETTINGS, OTHER SETTINGS). Copy the update file into the UTILITY folder on the card. Keep only one update file there.
    3. Eject the card on the computer, press DISCONNECT, and turn the X8 off.
    4. Hold HOME and REC while turning the X8 on, until UPDATE MODE shows.
    5. Press MARK. Check that the file's build matches the one in the table below.
    6. Press MARK again to install. Don't touch the power or the card until the X8 turns itself off.
    7. Delete the update file from the UTILITY folder.

    To go back to stock, install TASCAM's #PortaX8_0217.203 the same way.
