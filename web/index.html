X8 bat app emulator

The bat app's own code, running in the browser at 192 kHz. Recording is simulated: nothing is saved.

Input

No input yet. Open a file, drop one on the page, or use the microphone.

The browser has paused audio until you click the page or press a key.

Keys

HHOME: close the settings screen

← →Turn the wheel (or scroll over the screen)
1 to 5Mode: HET, COMB, FD, TE, PITCH
ClickTap the screen (on the waterfall in HET and COMB modes: tune there)

On the screen

Three lines at the top left: settings (lowest bat call, which input to listen to, which sounds to mark). File channels 1 and 2 play as inputs 3 and 4.
Solid line: the tuned frequency (HET, COMB)
Dashed lines: the band HET hears, 15 kHz either side
Box (TE): the window being captured or played back
Yellow ticks along the bottom: bat calls (calls in a train of similar calls)
Cyan ticks along the bottom: steady tones, if switched on in the settings under Sounds to mark
Pink ticks along the bottom: audible sounds, if switched on there
Grey ticks along the bottom: clicks and rustles, if switched on there
White ticks along the top: marks
White tick on a meter: highest level in the last 1.5 s
Coloured ticks on the kHz scale: resistor colour code for the tens digit (40 kHz is yellow), as in Oversample
